Cybersecurity Training Diary – 24 Days

Training Domain: Cybersecurity and Network Security
Duration: 24 Days
Tools Used: Kali Linux, Ubuntu Linux, Oracle VirtualBox, Wireshark, Nmap, Nikto

About the Training

This training diary documents my 24-day learning journey in cybersecurity, Linux administration, networking, cryptography, and network security. It includes theoretical learning, practical exercises, and hands-on experience with cybersecurity tools in a virtual lab environment.

Daily Training Log

Day 1 – Introduction to Cybersecurity

* Learned the fundamentals of cybersecurity and information security.
* Studied the CIA Triad: Confidentiality, Integrity, and Availability.
* Explored common cybersecurity threats and attacks.
* Understood the importance of protecting computer systems and networks.

Day 2 – Cybersecurity Threats and Attacks

* Studied malware, phishing, ransomware, and social engineering.
* Learned about vulnerabilities, exploits, and attack surfaces.
* Understood passive and active attacks.
* Explored basic security mechanisms.

Day 3 – Introduction to Linux

* Explored the Linux operating system and command-line interface.
* Learned the basic structure of the Linux file system.
* Practiced commands such as pwd, ls, cd, and whoami.
* Understood the importance of Linux in cybersecurity.

Day 4 – Linux File and Directory Management

* Practiced creating files using touch.
* Created and removed directories using mkdir and rmdir.
* Learned to copy and move files using cp and mv.
* Used cat and grep to view and search file contents.

Day 5 – Linux File Permissions and System Information

* Studied Linux file permissions and ownership.
* Practiced viewing permissions using ls -l.
* Explored system information using free -h and date.
* Learned about the Linux shell and environment variables.

Day 6 – Linux File Compression and Archiving

* Practiced compressing files using gzip.
* Learned to extract compressed files using gunzip.
* Explored ZIP file creation and extraction.
* Studied the use of tar for archiving files and directories.

Day 7 – Virtualization and Lab Environment

* Explored Oracle VirtualBox for creating virtual machines.
* Learned the purpose of virtualization in cybersecurity training.
* Studied NAT, bridged, and host-only networking.
* Prepared a virtual lab environment for practical exercises.

Day 8 – Computer Networking Fundamentals

* Studied the components of data communication.
* Learned about LAN, WAN, and network topologies.
* Explored IP addresses, MAC addresses, and network protocols.
* Understood the role of TCP/IP in communication.

Day 9 – OSI and TCP/IP Models

* Studied the seven layers of the OSI model.
* Learned the structure of the TCP/IP protocol suite.
* Understood encapsulation and decapsulation.
* Compared the OSI model with the TCP/IP model.

Day 10 – Network Addressing and Protocols

* Studied IPv4 and IPv6 addressing.
* Learned about DNS, DHCP, ARP, and ICMP.
* Explored TCP and UDP communication.
* Practiced identifying IP addresses and network interfaces in Linux.

Day 11 – Network Traffic Analysis Using Wireshark

* Explored Wireshark and its network interfaces.
* Learned how to select an interface for packet capture.
* Captured network traffic and explored packet details.
* Studied source addresses, destination addresses, and protocol information.

Day 12 – HTTP and HTTPS Analysis

* Captured HTTP traffic using Wireshark.
* Applied display filters such as http and tcp.
* Compared HTTP and HTTPS based on confidentiality and integrity.
* Understood how HTTPS uses TLS to protect communication.

Day 13 – Network Security Mechanisms

* Studied firewalls, intrusion detection systems, and intrusion prevention systems.
* Learned about network security policies and access control.
* Explored the role of encryption in secure communication.
* Understood the importance of monitoring network traffic.

Day 14 – Cryptography Fundamentals

* Studied the principles of cryptography.
* Compared symmetric and asymmetric encryption.
* Learned about plaintext, ciphertext, encryption, and decryption.
* Explored the importance of cryptographic keys.

Day 15 – Symmetric Encryption

* Studied the structure of DES and AES algorithms.
* Learned about block cipher modes: ECB, CBC, CFB, OFB, and CTR.
* Understood the importance of secure encryption techniques.
* Explored the limitations of insecure encryption practices.

Day 16 – Public Key Cryptography

* Studied the RSA algorithm and its working principles.
* Learned about the Diffie–Hellman key exchange.
* Understood the use of public and private keys.
* Explored how asymmetric cryptography supports secure communication.

Day 17 – Hash Functions and Digital Signatures

* Studied SHA-2 and SHA-3 hash functions.
* Learned about message authentication codes and HMAC.
* Explored the purpose of digital signatures.
* Understood how cryptographic techniques support data integrity and authentication.

Day 18 – Network Security Protocols

* Studied Transport Layer Security (TLS) and HTTPS.
* Explored SSH for secure remote administration.
* Learned about IPsec architecture.
* Studied email security mechanisms, including PGP and S/MIME.

Day 19 – Introduction to Nmap

* Explored Nmap as a network scanning tool.
* Learned how to identify active hosts in a virtual network.
* Practiced basic host discovery and port scanning.
* Understood how Nmap helps identify network services.

Day 20 – Service and Operating System Detection

* Practiced service version detection using Nmap.
* Explored operating system detection.
* Learned how to interpret open, closed, and filtered ports.
* Studied the importance of documenting scan results.

Day 21 – Vulnerability Assessment Using Nmap

* Explored Nmap vulnerability detection scripts.
* Learned how to identify potential security weaknesses.
* Studied the importance of validating scan results.
* Understood the need to perform vulnerability assessment only on authorized systems.

Day 22 – Web Server Assessment Using Nikto

* Explored Nikto as a web server assessment tool.
* Performed a scan against a deliberately vulnerable lab web server.
* Studied common web server misconfigurations and outdated software.
* Learned how to interpret potential security findings.

Day 23 – Network Packet Analysis and Security Review

* Reviewed ICMP, ARP, TCP, and HTTP packets in Wireshark.
* Practiced applying display filters to analyze network traffic.
* Compared network scanning and packet analysis techniques.
* Reviewed the security findings from the virtual lab exercises.

Day 24 – Training Review and Learning Outcomes

* Reviewed the concepts learned throughout the cybersecurity training.
* Consolidated Linux, networking, cryptography, and network security knowledge.
* Organized practical screenshots and training documentation.
* Identified areas for further learning in ethical hacking and network security.

Conclusion

This 24-day cybersecurity training helped me develop a foundational understanding of cybersecurity principles, Linux administration, networking, cryptography, and network security.

Through practical exercises and hands-on experience with tools such as Wireshark, Nmap, and Nikto, I gained knowledge of network traffic analysis, host discovery, service detection, and vulnerability assessment.

The training strengthened my interest in cybersecurity and provided a foundation for further learning in ethical hacking, penetration testing, and network security.
